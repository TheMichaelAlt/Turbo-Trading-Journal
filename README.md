The Turbo Trading Journal is a lightweight desktop application to log and analyze your trades, as well as journal your daily summary and notes on each trade you take.

It is completely free, open source, and runs locally on your device for complete data privacy.

**[Download for Windows — latest release](https://github.com/TheMichaelAlt/Turbo-Trading-Journal/releases/latest)**

On the release page, expand **Assets** and download the file ending in `Setup.exe`. Run it, then open Turbo Trading Journal from your desktop shortcut or Start menu.  The installer is unsigned, so Windows may show an unknown-publisher notice. You will have to trust unknown publisher to complete installation.

For updates, download the newest installer, run it, and it will update overwrite the previous version and retain your data. Your trades and journal pages stay in the same user-data folder. Updates are installed manually, so you will never get notifications or automatically update.

To check your version is up to date, compare your version number with the latest version number on the latest releases page linked above. To find your version number, go to settings in your Turbo Trading App and look in the bottom right corner.
